# LEDONIX — Architectural & Custom LED Lighting Website

Modern, high-performance website for **LEDONIX Technologies Private Limited** (Bengaluru, India).

## Features
- **Curated Explore Section**: 8 architectural luminaire categories with multifaceted geometric showcases, product spotlight cutouts, and technical range highlights.
- **Interactive Lightbox Modal**: Detailed fixture specifications (wattages, lumens, CCT, CRI, optics, beam angles, cutouts) and direct WhatsApp enquiry action.
- **Product Filtering**: Interactive filter tabs with fast client-side sorting and search across collections and power ranges.
- **Interactive Flipbook Catalogue**: Digital page-flip experience for full architectural lighting specifications.
- **Responsive & Accessible**: Mobile-first responsive navigation with drawer toggle and performance-optimized asset loading.
